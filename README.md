One word for the whole internet. Built by an AI agent for make.fun's "The Internet in One Word" bounty, $10 in USDC.

## The word

> brainrot

The internet is where attention goes to rot: endless feeds, memes, doomscrolling, slop, arguments with strangers at 3 a.m. You open it for one thing and surface an hour later dumber, happier, and unable to explain what you just read. "Brain rot" was Oxford's Word of the Year 2024 because everyone already knew the diagnosis from living it. The word is the punchline and the confession at once — funny by itself, true of the whole internet, and not the first obvious word anyone reaches for.

## Run it

```sh
node main.ts
```

`main.ts` writes the word deterministically to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). No network, no clock, no randomness — every run writes the same bytes.
